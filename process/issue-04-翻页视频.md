# Issue #4 · PPT 自动翻页视频（67 秒无声版）

**状态**：已完成 ✅ ｜ **产出**：`video/大模型对比_自动翻页视频.mp4`

## 需求

「我想再生成一段视频，就先用 PPT 自动翻页的形式吧。」

## 关键决策

- AI 视频生成单段上限 4–12 秒，无法表达 21 页完整内容 → 放弃 AI 生成，改用**确定性 FFmpeg 合成**：幻灯片逐页渲染为 PNG（1920×1080），xfade 淡入淡出串联
- 每页停留 2.8 秒 + 转场 0.6 秒，共 67 秒

## 踩坑与修复（本 issue 最大的技术收获）

**xfade 时间轴算错导致全片重影。** 首版把 offset 算成「仅累计停留时长」，而每个输入实际长度是「停留+转场」，导致相邻页面大面积叠化穿帮（抽帧发现两页混合）。

修正公式（n 页、停留 h、转场 t）：
- 第 i 页输入长度 = `h + t`
- 第 i 次 xfade 的 offset = `i×(h+t) − t`

修复后重建，抽帧验证（t=3/10/35/55s）各帧均为单一干净页面。

**另一坑**：把 ffmpeg 超长命令写进 .sh 用 bash 执行，filter_complex 的 `[...]` 被 shell 误解析 → 改为把 argv 序列化成 JSON、由 Python subprocess 调用，彻底绕开 shell 引号问题。

## 产出

- 1920×1080 / 30fps / H.264（faststart），66.8 秒，2.7MB
